# E-Commerce Sales Intelligence

## 📊 Project Overview

E-Commerce Sales Intelligence is an end-to-end data analytics project focused on analyzing e-commerce sales performance, customer behavior, profitability, and order operations.

The project uses Python for data cleaning and exploratory analysis, SQL for business-oriented data analysis, and Power BI for interactive dashboard development.

## 🎯 Business Objectives

- Analyze overall sales and profitability performance
- Identify high-performing product categories and sub-categories
- Analyze revenue and profit trends over time
- Understand customer segment performance
- Analyze regional sales performance
- Identify top-performing products
- Analyze order status and payment methods
- Develop an interactive executive dashboard for business insights

## 🛠️ Tools & Technologies

- **Python** — Data Cleaning, Exploratory Data Analysis and Business Insights
- **SQL** — Data querying and business analysis
- **Power BI** — Interactive Dashboard and Data Visualization
- **Pandas & NumPy** — Data manipulation
- **Matplotlib & Seaborn** — Data visualization
